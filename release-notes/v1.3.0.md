## AT Music Pro 1.3.0 — Liquid Glass

### New
- **Liquid Glass design** — translucent floating sidebar, player capsule and panels over a backdrop built from the current album art. Works with Light, Dark and OLED. Toggle in Settings → Theme & Appearance.
- **Desktop widget** — minimize to the taskbar and a small always-on-top player appears. Three styles: Pill, Card, Orb. Pin, seek, open app, hide. Remembers its position.
- **Glass mini player** with round controls and blurred artwork backdrop.
- **GPU acceleration toggle** (Settings). On by default on Windows/macOS.

### Fixed
- Repeat-one now repeats; Next after picking a song no longer replays the previous one; Previous keeps the current track.
- Equalizer settings persist across songs and restarts.
- Rescanning a folder no longer breaks playlists; removing `/Music` no longer deletes `/Music2`.
- Downloads now write your custom title/artist/album tags; thumbnail option respected; no more stuck downloads.
- Spotify playback, ffmpeg video mode and http artwork were blocked — now work.
- Album list duplicates, NaN album years, corrupt cached images.
- Single-instance lock; crash on macOS window re-open.

### Faster
- UI no longer re-renders 4× per second during playback.
- Startup bundle halved (461 KB → 219 KB) with on-demand pages.
- Stream URLs reused, library scans skip unchanged files, no background YouTube lookups unless video mode is opened.

### Notes
- Builds are not code-signed. Windows SmartScreen: *More info → Run anyway*. macOS: right-click the app → *Open* the first time (or `xattr -dr com.apple.quarantine "/Applications/AT Music Pro.app"`).
